# App icon spec

First-party launcher icons (`apps/<app>/assets/icon.svg`). Every icon is
generated by `scripts/build-app-icons.py`; change the script, not the SVGs.

The system is Shipwright's (`Shipwright/icons/make-icons.py`, the Reef,
Shoal and Pilot icons), which is Jolla's Sailfish OS launcher icon system
(sailfishos.org/design/icons). The generator is a port of that one, so
Marathon's apps and the Shipwright apps sit side by side as one family.

## Frame

| | |
|---|---|
| Canvas | 86 × 86 (`viewBox="0 0 86 86"`), no padding beyond a 0.3 gap per side |
| Shape | one of Sailfish's 16 base shapes: each corner a quarter circle (r 42.7) or near square (r 1.423) |
| Family | the square corner. Reef: the leaf. Shoal: bottom right. Pilot: top right. **Marathon: bottom left** |
| Frame | gradient of the hue's frame tone, bottom left (mid) to top right (light) |
| Face | cream (`#F1EBD3` → `#FCF8EA`), the same shape inset 8, with a faint inner shadow |
| Shell chrome | none: the launcher draws the SVG as is, like Sailfish's |

Marathon's icons carry no family mark: the two reef bands in the frame are
Shipwright's.

## Colour

One hue per icon, and only that hue. Each hue gives these tones, every one a
gradient along the frame's diagonal so all surfaces read matte:

| Tone | OKLCH (L, C) | Role |
|---|---|---|
| F | 0.62 → 0.80, 0.18 → 0.14 | frame |
| D | 0.45 → 0.57, 0.16 | the object |
| E | 0.37 → 0.48, 0.14 | the object's darker facet |
| L | 0.56 → 0.68, 0.15 | a lighter plane |
| T | 0.80 → 0.88, 0.09 | pale tint |
| R | radial 0.68 → 0.45 | glass (Camera lens) |
| C | cream | cut-outs, in the face's colour |

Yellows (hue 45–110) sit 0.09 lighter in D/E/L/R so they read ochre, not
brown.

Hues are steps of 22.5° round the OKLCH wheel, starting at 10°, so every
icon has the same weight. Store takes 167.5°, the step on Marathon teal
(`--teal-bright` is ≈ 172°). The rest were assigned so that no two icons
next to each other on the home grid are closer than 45°, keeping the
conventional hue where there is one (Phone green, Calendar red, Notes and
Clock yellow, Browser blue), and no Marathon app shares the hue of the
Shoal app that does the same job (Mail 262°, Messages 150°, Camera 330°,
Pacific 118°).

## Objects

One flat object per icon, built from the frame: the base shape inset
concentrically (bubble, envelope, pin), or circles and arcs about the centre
(globe, record, dial, gear), with details cut out in cream. Every cut-out
line is 3.6 wide with round caps and joins. No text elements (lunasvg can't
match fonts); the Store mark is a path.

| App | Object |
|---|---|
| Phone | handset (D) |
| Messages | the inset shape as a speech bubble, its tail the square corner; two lines cut |
| Mail | the inset shape as an envelope, flap in E, fold cut |
| Browser | globe: disc, meridian and equator cut |
| Store | the inset shape with the Marathon M cut through |
| Music | record: E disc, T grooves catching light, T label |
| Camera | body (D), lens ring cut, R glass, highlight |
| Gallery | T sky, D hills, cream sun |
| Maps | the family shape turned so its square corner points down: a pin, hole cut |
| Calendar | page (D) with E header, binder rings and days cut |
| Clock | dial (D), hands cut |
| Calculator | the inset shape with + − × = cut |
| Notes | page (D) with its corner turned down (E), lines cut |
| Settings | gear about the centre, hub cut |
| Terminal | the inset shape in E as a screen, prompt cut, cursor in T |
| Test | flask (T) with D liquid, bubbles cut |

## Sizes

The SVG is the one shipped asset; the shell renders it with lunasvg at
`Theme.iconSizeLauncher`. Check every change at Sailfish's launcher sizes
86, 108, 128 and 172 and at 43 for lists.

Third-party and desktop apps (Foot, Htop, Megapixels, …) keep their own icons.

## Adding an icon

Add a draw function and an `ICONS` entry with a free hue from the wheel
(not within 45° of its grid neighbours), run the script, and review it on a
contact sheet next to the rest and next to the Shipwright icons.
