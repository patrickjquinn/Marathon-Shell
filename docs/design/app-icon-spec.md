# App icon spec

First-party launcher icons (`apps/<app>/assets/icon.svg`). Every icon is
generated by `scripts/build-app-icons.py`; change the script, not the SVGs.

The system is Shipwright's (`Shipwright/icons/make-icons.py`), which builds
on Jolla's launcher template (sailfishos.org/design/icons). Marathon's apps
are a fourth family beside Shipwright's Reef, Shoal and Pilot: same frame,
face, palette and drawing rules, a different square corner. They are not
copies of Jolla's stock icons.

## Shape

| | |
|---|---|
| Canvas | 86 × 86 (`viewBox="0 0 86 86"`), a 0.3 gap per side |
| Shape | the Sailfish base shape: each corner a quarter circle (r 42.7) or near square (r 1.423) |
| Family | **bottom-left corner square** (Reef: leaf; Shoal: bottom right; Pilot: top right) |
| Frame | the shape in the hue's frame gradient |
| Face | the shape inset 8, cream (`#F1EBD3` → `#FCF8EA`), with a faint inner shadow (black 8 %, 3 px, clipped) |
| Shell chrome | none: the launcher draws the SVG as is |

## Colour

One OKLCH hue h per icon and only that hue. Each tone is a two-stop
gradient on the frame's diagonal (bottom left → top right):

| Tone | Stops (L, C, hue) | Role |
|---|---|---|
| F | 0.62, 0.18, h → 0.80, 0.14, h + 15 | frame |
| D | 0.45, 0.16, h → 0.57, 0.15, h + 6 | the object |
| E | 0.37, 0.14, h → 0.48, 0.14, h + 6 | its darker facet |
| L | 0.56, 0.15, h → 0.68, 0.13, h + 6 | a lighter plane |
| T | 0.80, 0.09, h → 0.88, 0.07, h + 6 | a pale tint |
| R | radial, 0.68 centre → 0.45 edge | glass (the camera lens) |

Yellows (h 45–110) sit 0.09 lighter in D, E, L and R so they stay ochre.
Details are cut out in the face's cream.

Hues are 22.5° steps round the wheel, no two home-grid neighbours (4
columns) closer than 45°:

| App | Hue | App | Hue |
|---|---|---|---|
| Phone | 145 | Maps | 257.5 |
| Messages | 212.5 | Calendar | 10 |
| Mail | 280 | Clock | 77.5 |
| Browser | 235 | Calculator | 167.5 |
| Store | 190 | Notes | 100 |
| Music | 325 | Settings | 55 |
| Camera | 32.5 | Terminal | 122.5 |
| Gallery | 302.5 | Test | 347.5 |

## Object

One flat object on the face, built from the frame: the shape set in
concentrically (the bubble, envelope, bag, picture, page, screen; Maps' pin
is the shape turned so its square corner points down), or circles and arcs
about the centre (globe, lens, dial, wheel). Calculator's keys are the
shape in small. The square corner is used where the metaphor has one: the
bubble's tail, the handset bowed into it, the hour hand, the folded page.
Cut-out lines are 3.4 wide with round caps.
