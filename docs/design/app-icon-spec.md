# App icon spec

First-party launcher icons (`apps/<app>/assets/icon.svg`). Every icon is
generated by `scripts/build-app-icons.py`; change the script, not the SVGs.

The system is Jolla's Sailfish OS launcher icon system
(sailfishos.org/design/icons: the Apps icon story, the launcher template and
the stock icon library in `Sailfish-Apps-icon-template.zip`). Marathon's set
is measured against those stock icons, side by side, at launcher sizes.

## Shape

| | |
|---|---|
| Canvas | 86 × 86 (`viewBox="0 0 86 86"`), no padding beyond a 0.3 gap per side |
| Shape | Sailfish's base shape: each corner a quarter circle (r 42.7) or near square (r 1.423) |
| Family | **one shape for every icon: the bottom-left corner square** |
| Guide | the shape inset 10.7 (round corners r 32.0), Jolla's template guide for the metaphor |
| Shell chrome | none: the launcher draws the SVG as is, like Sailfish's |

Jolla's icon story gives each app the base shape that suits its metaphor.
Marathon keeps one shape so its apps read as one set next to Shipwright's
(Reef the leaf, Shoal bottom right, Pilot top right), and takes the square
corner as a cue where the metaphor has one: the bubble's tail, the handset
bowed into it, the hour hand, the = key, the folded page, the small gear.

## Field

The shape is the colour, as on the stock icons: no frame, no face, no
sticker. A two-stop linear gradient from the square corner (0.717, 85.283),
deep, to the top right's guide point (73.194, 12.806), light, which is the
stock Settings icon's axis on the same shape.

Measured on the stock library (OKLCH): deep stops L 0.50–0.66, light stops
L 0.68–0.85, chroma 0.10–0.22, and the hue turns 30–60° between them, the
light end toward yellow (Phone 183° → 141°, Clock 44° → 72°, Settings 47° →
95°). Marathon makes that one rule:

| Stop | OKLCH |
|---|---|
| deep | L 0.57, C 0.17, hue h − s |
| light | L 0.77, C 0.17, hue h + s |

where s is the turn from h toward the warm light (95°), at most 22°.
Yellows (within 50° of 95°) sit up to 0.09 lighter so they stay ochre, not
brown. The stock icons have no inner shadows or edge shading; the light is
the gradient alone, so Marathon's is too.

Objects that are paper (Calendar, Notes) take the whole shape as the page
(`#EFE8CF` → `#FBF8EA`) and carry the hue in a band across its top, as the
stock Calendar and Notes do.

## Tones

| Tone | OKLCH | Role |
|---|---|---|
| P | 0.96, 0.045, h + s/2 | the object, drawn at 0.9 opacity so the field shows through |
| M | 0.87, 0.05 | P's muted shade (ruled lines) |
| Q | 0.86, 0.15 | the second plane: a grip, a hem, a fold, a map panel, the days |
| K | 0.47, 0.11, 237° | ink: Jolla's stock ink blue (`#1472A0` is 0.52, 0.11, 237°); fields within 50° of it ink in their own deep tone (0.42, 0.14, h) |
| N | 0.27, 0.04, h | dark bodies: the lens barrel, the terminal screen |
| A | per icon | one accent where the metaphor has one |

Real-world paper (the envelope) is cream whatever the field.

(4 columns, home grid order) closer than 45°, conventional hues kept (Phone

## Objects

One big, bold, flat object per icon, reading as the stock metaphor first.
It fills the guide (reaching to about 10.7 from the edge, as the stock
objects do), with at most one second plane and one accent. No outlines, no
text elements (lunasvg can't match fonts), no filters.

| App | Object |
|---|---|
| Phone | a handset bowed into the square corner, ear and mouth pieces (P) turned toward the top right, grip Q |
| Messages | the guide shape as the bubble, its tail the square corner; three ink dots |
| Mail | a cream envelope across the guide, the flap and lower fold lighter |
| Browser | the guide circle as the globe; meridian, equator and two curved parallels in ink |
| Store | a shopping bag, a Q hem, the handle above, two ink rivets |
| Music | two beamed quavers in P |
| Camera | a lens: the barrel (N) fills the guide, deep blue glass, a highlight arc, an accent glint |
| Gallery | four petals, each the family shape at 0.47 with its square corner at the centre, overlapping at 0.82 opacity |
| Maps | a map folded in three (middle panel Q), an ink route, a red pin: the family shape turned so its square corner points down |
| Calendar | the page; the hue a band across the top; a 4 × 3 month in Q, today in ink |
| Clock | the guide circle as the dial; ink hands, the hour hand pointing into the square corner |
| Calculator | + ÷ × in P on the field; the square corner's quarter is the = key in the accent |
| Notes | the page; the hue a band across the top, ruled in M, an ink scribble, the square corner folded over (Q) |
| Settings | a gear on the guide in P; a small Q gear turning in the square corner |
| Terminal | a dark screen (N) across the guide, the prompt in the accent |
| Test | a flask in P, the liquid below its shoulder in the accent, two bubbles |

### Store: bag, not the M

At 43 px the bag reads as a store (the platform-wide metaphor); the M reads
as a letter, and as Marathon itself: it is the OS mark (`MMarathonMark.qml`,
the OOBE), so on the home grid it would look like an "About Marathon" or
settings entry rather than the place to get apps. Every other icon is a
metaphor, not a letterform; Jolla's own lettered Store icon is the stock
set's odd one out.

## Sizes

The SVG is the one shipped asset; the shell renders it with lunasvg at
`Theme.iconSizeLauncher`. Check every change at Sailfish's launcher sizes
86, 108, 128 and 172 and at 43 for lists.

Third-party and desktop apps (Foot, Htop, Megapixels, …) keep their own icons.

## Adding an icon

Add a draw function and an `ICONS` entry with a free hue from the wheel
(not within 45° of its grid neighbours) and an accent only if the metaphor
has one. Draw one object inside the guide from P (via `Art.pale`), Q, K, N
and A; then add rows to the tables above. Run the script, and review the
icon on a contact sheet that pairs each Marathon icon with Jolla's stock
icon at 128, 86 and 43 px.
